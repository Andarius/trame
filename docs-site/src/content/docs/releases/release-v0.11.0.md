A small display release for databases attached to pages.

## Databases

- Databases attached to a page now break out of the page's text column and use
  the full content pane width (up to 1400px), so inline tables are no longer
  cramped.
- Title cells drop the redundant "open full text" button — "open row" already
  sits in the same spot.
- Text and URL cell hover buttons use the same bordered chip style as
  "open row" for a consistent affordance.
