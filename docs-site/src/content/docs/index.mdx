## Install

```bash
curl -fsSL https://raw.githubusercontent.com/Andarius/trame/master/bin/quickstart.sh | bash
```

Linux x64 (snap, deb, AppImage) and macOS arm64 (DMG). The script installs the latest release and the agent skills for
Claude Code and Codex; [read it](https://github.com/Andarius/trame/blob/master/bin/quickstart.sh) first, or download a
package from the [releases page](https://github.com/Andarius/trame/releases). Then open Trame, start an agent from
**New terminal**, and run `/trame-track` in it.


<Feature n="01" title="Every agent in one sidebar" shot="agents-sidebar.png" alt="The agents sidebar: one agent needs you, four others grouped by project with their current step" tall>

Start Claude Code, Codex, Antigravity, Mistral Vibe or Pi from **New terminal**. The sidebar groups running agents by
project and shows what each is doing. The one waiting for an answer moves to **Needs you**.

Forks and subagents sit under the session that started them. Tabs, split panes and pop-out windows
keep the terminals in one place.

</Feature>

<Feature n="02" title="Every session is a card" shot="board.png" alt="The board: sessions as cards in Active, Paused, Blocked and Done columns">

`/trame-track` from any agent session files it on the board with its repo, branch and a one-line note, or updates its
status: `paused`, `blocked`, `done`. Columns are yours to define; swimlanes group cards by project or story.

</Feature>

<Feature n="03" title="Resume next week" shot="sessions-resume.gif" alt="Resuming a past session from its card">

A card keeps the session's id. **Resume** reopens it in Claude Code or Codex, in the right folder, days later.

</Feature>

<Feature n="04" title="Pages your agents work in" shot="decision.gif" alt="An agent's question in a page, answered by picking an option">

Plans, specs and notes are Markdown pages with todos. Agents write them through `tramecli` or MCP, leave review
comments on a block, and answer your replies. When an agent needs a decision, it asks in the page and reads the
answer back.

Pages also hold sandboxed HTML blocks, Notion-style databases, and read-only share links.

</Feature>

<Feature n="05" title="Local-first, sync if you want" shot="page.png" alt="A page next to the board in Trame">

Everything runs and is stored on your machine, in a bundled PostgreSQL 18, offline. No account, no cloud.

To use several machines, run the [hub](sync-walkthrough/) on a server you own: edits reach the other machines in a
couple of seconds.

</Feature>

## FAQ

<details>
<summary>Do I need a server or an account?</summary>

No. Trame works on one machine with no network. The hub is only for syncing several machines.

</details>

<details>
<summary>What does it change in my agent setup?</summary>

`tramecli setup` writes the Trame skills to `~/.claude/skills/` (or any skills directory you pass) and links
`tramecli` into `~/.local/bin`. With `--presence` it also adds hooks to `~/.claude/settings.json` and
`~/.codex/hooks.json`, which report which agent is working or waiting. The
[security notes](https://github.com/Andarius/trame/blob/master/SECURITY.md) list everything it touches.

</details>

<details>
<summary>Does it send anything anywhere?</summary>

No telemetry. Out of the box, the only request is a release check against the GitHub API every 6 hours
(`TRACKER_UPDATE_CHECK=0` turns it off). The hub and plugins only reach the network once you configure them.

</details>

<details>
<summary>Why a whole PostgreSQL inside a desktop app?</summary>

The laptop and the hub run the same schema and the same SQL, so offline writes and sync need no translation layer.
Postgres runs with no TCP port, on a private Unix socket.

</details>

<details>
<summary>What doesn't it do?</summary>

There is no Windows or Intel Mac build. The hub has to be self-hosted, and it is built for a home LAN or a VPN, not
the open internet. Trame is pre-1.0: releases are frequent, and the hub must be upgraded before the laptops when the
sync protocol changes.

</details>

<details>
<summary>How do I suggest something?</summary>

[Open an issue](https://github.com/Andarius/trame/issues/new/choose). Ideas are as welcome as bugs. Code is
dual-licensed MIT or Apache-2.0.

</details>
